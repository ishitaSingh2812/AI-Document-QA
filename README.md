# AI Document Question Answering System

## Overview
This project is an AI-powered Document Question Answering System built using FastAPI, LangChain, and ChromaDB.

The system allows users to upload a PDF document and ask questions related to the document. The application retrieves relevant content from the document and returns contextual answers.

---

## Features
- PDF document loading
- Document chunking
- Semantic search
- Vector database using ChromaDB
- Question answering from documents
- FastAPI Swagger UI

---

## Technologies Used
- Python
- FastAPI
- LangChain
- ChromaDB
- HuggingFace Embeddings
